# Provider-neutral history (internal review)

MODEL_HISTORY_ENABLED is false by default. The compatibility adapter preserves existing Meta request objects/fields and response IDs; its legacy provider-owned continuation behavior remains isolated in model-adapter.ts. under.ts no longer chooses a provider by response-ID prefix. The flag does not select a new default provider or expand consent. No production environment setting was changed.

With the flag on, modelFor stores account-scoped normalized turns in Postgres (migration 031), returns opaque app-owned IDs and reconstructs the conversation for every call. Each call tries Meta first and follows the existing fallback/cap rules, including a switch in the middle of a conversation. Another instance can load the same history. Neither provider receives previous_response_id. Text, images, function calls/results and untrusted built-in search evidence are carried as Responses-style content; tool outputs are checked against pending call IDs, never executed by this adapter. Explicit failures/cancellation do not save successful turns or retry external actions.

ModelAdapter is the extension point for a separately evaluated AWS or lightweight on-device backend. Non-Meta adapters set needsSchemaPrompt so field descriptions appear in the prompt as well as the structured-output schema. The current Claude client still translates that neutral shape to its SDK. No new provider, runtime, credentials or model call was introduced. Speech/image/segmentation models stay on their capability-specific Meta path.

Transcripts are private DB data, never logged. History is limited to 400 items/2 MB per snapshot, expires after one hour, and is deleted on account deletion; expired rows are swept on a later save. No invalid/expired/other-account/provider-owned ID is silently sent to a provider in the new lane. Unknown history fails closed; a caller must explicitly start a new conversation. Parallel follow-ups can form independent branches, as Responses-style continuations do; this adapter does not perform tools or reconcile application side effects.

Parity and fallback tests use PGlite and inert provider functions only. The history-on path has not been accepted against live Meta/Claude, actual tool-provider behavior or device/AWS runtimes. Flag-off compatibility remains the release default pending Claude review and a separate GO. Account consent middleware and UI are unchanged.
